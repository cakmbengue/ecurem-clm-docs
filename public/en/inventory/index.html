Inventory

Use the Asset List to separate known domains, observed certificates and assets that actually require action.

On this page1. Inventory view2. Certificates3. Domains4. Indicators5. Certificate details6. Cryptographic data7. Tags8. Recommended workflow

1. Inventory view

Inventory opens the Asset List for the active organization, with Certificates and Domains tabs.

2. Certificates

Summary cards include total certificates, active certificates, certificates expiring soon and critical certificates. Use this view to confirm scope before Renewal.

3. Domains

The Domains tab summarizes known domains, including active and inactive state. A known domain is not automatically an asset that should be renewed.

4. Indicators

  • Active/valid: monitor normally.
  • Expiring soon: prepare validation and renewal.
  • Critical: review expiry, trust, algorithms, key size, TLS context and findings.
  • Inactive: determine whether the asset should remain in scope.

5. Certificate details

Review domain, subject, issuer, serial number, validity, fingerprint, algorithms and available security evidence. For Discovery-originated observations, also review target and port.

6. Cryptographic data

Where evidence is available, Ecurem CLM can expose signature/public-key algorithms, key size, observed TLS version and cipher suite, classical/hybrid/post-quantum classification and cryptographic findings.

7. Tags

Use tags such as prod, demo, renewal-auto or renewal-manual to organize operational scope.

8. Recommended workflow

  1. Add domains.
  2. Run authorized Discovery.
  3. Review Inventory.
  4. Tag managed assets.
  5. Prioritize expirations and risk.
  6. Enable validation/Renewal only for managed assets.
  7. Use Reports for posture tracking.
