Domain validation

Validate one or more domains before renewal or issuance operations that require proof of control.

On this page1. Form2. Methods3. Bulk validation4. Track status5. Troubleshooting

1. Form

The Renewal validation form asks for Domains and Validation method. Ecurem CLM queues an asynchronous validation task for the selected domains.

2. Methods

Renewal policies support DNS, HTTP, Email and Auto-detection validation. The actual path depends on provider and workflow configuration.

3. Bulk validation

Select only domains your organization is authorized to validate. Bulk execution does not expand authorization.

4. Track status

Validation attempts keep domain, method, status, attempt count, last attempt, verification data, error, validation time and expiration where applicable.

5. Troubleshooting

  • DNS: verify API permissions, zone and propagation.
  • HTTP: verify public reachability and routing.
  • Email: verify the method is supported and operational.
  • Repeated failures: correct the cause before retrying.
