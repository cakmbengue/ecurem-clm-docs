Troubleshooting

First-level procedure for diagnosing common issues.

On this pageA scan does not startA scan finds nothingDomain validation failsRenewal failsThe new certificate is not visibleEscalation

A scan does not start

  1. Check the configuration.
  2. For local scans, check Agent status.
  3. Confirm scope and targets.
  4. Review the job log.

A scan finds nothing

Confirm targets are reachable, expected ports are open and a TLS service is actually present.

Domain validation fails

Check the domain, validation method, DNS permissions if applicable, and propagation before retrying.

Renewal fails

Check domain validation, CA or provider access, policy, deployment target and job log.

The new certificate is not visible

Verify the target service directly. Successful issuance does not guarantee the application already serves the new certificate.

Escalation

For support, provide approximate time, organization, operation type and job identifier. Never send private keys or secrets.
