Discovery Agent

Deploy and operate the Discovery Agent for visibility into internal networks.

On this pageWhen to use the AgentEnrollmentConnectivityUpdatesTroubleshooting

When to use the Agent

Use the Agent when targets are not directly reachable from the SaaS service or when a scan must originate from the customer network.

Enrollment

The Agent must be enrolled in the expected organization. Confirm its status before assigning scans.

Connectivity

The Agent must reach Ecurem CLM over HTTPS and the configured internal targets. Firewall rules should remain limited to actual requirements.

Updates

Use an Agent version approved by your organization and plan updates like any other operational component.

Troubleshooting

Check Agent status, HTTPS connectivity, target reachability and the job log first.
