NETWORK

Network & firewall

Connectivity principles for users, Agents and Discovery operations.

SaaS access

Users and authorized components access Ecurem CLM over HTTPS.

Agent to SaaS

The Discovery Agent must be able to reach Ecurem CLM over the organization’s expected HTTPS path.

Local Discovery

A local scan requires the Agent to reach targets and ports included in the authorized scope. Firewall rules should remain limited to actual requirements.

Least exposure

Do not open inbound ports to the Agent solely for SaaS operation unless the architecture explicitly requires them.
