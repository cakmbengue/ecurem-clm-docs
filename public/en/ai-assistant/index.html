AI ASSISTANT

AI Assistant

Ask questions about your Ecurem CLM environment in natural language, within the active organization and through read-only tools.

On this page1. Data Aida can consult2. Conversations3. Useful questions4. Evidence5. Security6. Limits

1. Data Aida can consult

The server fixes the current organization. Read-only tools can provide inventory summaries, expiring certificates, certificate details and cryptographic posture, Discovery configurations/jobs/results/Agents, Renewal policies/history/domain validation, compliance campaigns/findings/remediations, notifications, subscription information and Client PKI summaries.

2. Conversations

Select New conversation and ask a precise question. Conversations are persistent and bound to the current user and organization.

3. Useful questions

  • Which certificates expire in the next 30 days?
  • Why is this certificate critical?
  • What is the status of my latest Discovery job?
  • Which domain validations failed?
  • Summarize active Renewal policies.
  • What is my current post-quantum visibility?

4. Evidence

Aida should use server-provided tools before making claims about operational data. Missing evidence should be reported as missing rather than guessed.

5. Security

  • Organization scope is fixed server-side.
  • Documented assistant tools are read-only.
  • Untrusted stored text cannot grant access.
  • Never paste passwords, private keys, API tokens or DNS secrets.

6. Limits

Message and conversation limits can depend on the active plan. The interface indicates when a configured quota is reached.
