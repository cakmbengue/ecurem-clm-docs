Validation de domaine

Valider un ou plusieurs domaines avant les opérations de renouvellement ou d’émission qui exigent une preuve de contrôle.

Dans cette page1. Le formulaire2. Méthodes3. Validation groupée4. Suivre le résultat5. Dépannage

1. Le formulaire

Le formulaire de validation Renewal demande deux éléments : Domaines et Méthode de validation. Seuls les domaines accessibles dans votre organisation doivent être sélectionnés.

Après validation du formulaire, Ecurem CLM lance une tâche asynchrone pour l’ensemble des domaines sélectionnés et affiche l’identifiant de tâche.

2. Méthodes

Les politiques Renewal supportent les méthodes DNS, HTTP, Email et Auto-détection. Le chemin réellement utilisé dépend du fournisseur et du workflow configuré.

Pour DNS, vérifiez que le compte DNS de l’organisation possède uniquement les droits nécessaires à la création/lecture des enregistrements de validation.

3. Validation groupée

La validation groupée est utile lorsque plusieurs domaines doivent être revalidés avant un renouvellement. Sélectionnez uniquement les domaines dont votre organisation contrôle réellement la zone ou le mécanisme de validation.

Une action groupée n’est pas une autorisation implicite. Vérifiez le périmètre avant de lancer la tâche.

4. Suivre le résultat

Les tentatives de validation conservent notamment le domaine, la méthode, le statut, le nombre de tentatives, la dernière tentative, les données de vérification, l’erreur, la date de validation et l’expiration éventuelle.

Dans Renewal, utilisez l’historique et les tentatives de validation pour distinguer un problème de contrôle de domaine d’un problème d’émission ou de déploiement.

5. Dépannage

  • DNS : vérifiez droits API, zone, propagation et enregistrement attendu.
  • HTTP : vérifiez accessibilité HTTP et routage vers le bon serveur.
  • Email : vérifiez que la méthode est autorisée et que le canal est exploitable.
  • Échecs répétés : corrigez la cause avant de relancer en boucle.
