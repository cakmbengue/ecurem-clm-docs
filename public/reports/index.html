Rapports & conformité

Transformer l’Inventaire cryptographique en évaluations, constats, preuves et exports utilisables pour les revues de sécurité.

Dans cette page 1. Tableau de bord 2. Périmètres 3. Lancer une évaluation 4. Lire les indicateurs 5. Contrôles et constats 6. Exports 7. Interpréter correctement

1. Tableau de bord

Le menu Rapports mène au tableau de bord de conformité et de préparation cryptographique. La vue est limitée à l’organisation active.

Vous y retrouvez notamment les actions Gérer les périmètres et Lancer une évaluation.

2. Périmètres

Un périmètre définit les actifs inclus dans une évaluation. Avant de lancer une campagne, vérifiez que le périmètre correspond bien au service, à l’environnement ou à l’organisation que vous souhaitez mesurer.

Un bon périmètre évite de mélanger certificats de démonstration, préproduction et production dans la même conclusion.

3. Lancer une évaluation

Une évaluation produit une campagne de conformité sur les actifs du périmètre choisi. Les contrôles disponibles analysent les données réellement présentes dans l’Inventaire et les preuves cryptographiques observées.

Une campagne peut ensuite être ouverte pour consulter ses contrôles, preuves, constats et actions de remédiation.

4. Lire les indicateurs

Le tableau de bord peut présenter notamment :

  • Certificats évaluables ;
  • Certificats expirés ;
  • Algorithmes faibles ;
  • Chaînes non fiables ;
  • Visibilité post-quantique ;
  • Actions ouvertes.

Ces indicateurs dépendent des preuves disponibles. Par exemple, si la version TLS ou la taille de clé n’est pas connue pour un actif, un contrôle peut être marqué non évalué plutôt que conforme.

5. Contrôles et constats

Pour chaque contrôle, examinez le statut, le résumé, le niveau d’assurance et les preuves associées. Les constats servent à identifier les éléments nécessitant une revue ou une remédiation.

Les informations de préparation post-quantique distinguent les observations classiques, hybrides et post-quantiques lorsqu’elles sont techniquement démontrables.

6. Exports

Une campagne client peut être exportée sous plusieurs formes :

  • CSV de campagne pour l’analyse tabulaire ;
  • CSV de preuves pour examiner les éléments techniques ;
  • Rapport PDF pour une diffusion structurée.

D’autres rapports de conformité peuvent également être générés et téléchargés depuis les écrans prévus à cet effet.

7. Interpréter correctement

Important : absence de preuve ≠ conformité. Un contrôle « non évalué » signifie que les données nécessaires ne permettent pas de conclure.

Avant de partager un rapport, vérifiez l’organisation, le périmètre, la date de collecte et les actifs inclus.
