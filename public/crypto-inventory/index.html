1. À quoi sert l’Inventaire cryptographique ?

L’Inventaire cryptographique complète l’inventaire traditionnel des certificats. Il permet de regrouper les informations techniques utiles pour comprendre les mécanismes cryptographiques réellement observés dans le périmètre de l’organisation.

Cette vue aide notamment à identifier les actifs utilisant des mécanismes classiques, hybrides ou post-quantiques, ainsi que les éléments nécessitant une revue en raison d’une faiblesse cryptographique ou d’un niveau de risque élevé.

2. Actifs cryptographiques

La vue Actifs cryptographiques permet d’examiner les éléments techniques associés aux certificats et aux observations réseau disponibles.

Selon les données collectées, un actif peut notamment exposer :

  • les algorithmes cryptographiques observés ;
  • la taille et le type de clé publique ;
  • les protocoles TLS observés ;
  • les suites cryptographiques ;
  • le contexte d’observation réseau ;
  • la classification post-quantique ;
  • le niveau de risque calculé ;
  • les constats associés.

3. Les 12 indicateurs

La Liste des actifs présente douze cartes de synthèse :

  • Total certificats ;
  • Post-quantiques ;
  • Hybrides ;
  • Clés faibles ;
  • Protocoles obsolètes ;
  • Endpoints observés ;
  • Vulnérables au quantique ;
  • Résistants au quantique ;
  • Risque faible ;
  • Risque moyen ;
  • Risque élevé ;
  • Risque critique.

Chaque indicateur peut être utilisé comme filtre pour limiter la liste aux actifs correspondant à la catégorie sélectionnée.

Les compteurs et les filtres utilisent la même logique de classification afin que la valeur affichée dans une carte corresponde aux actifs obtenus après sélection de cette carte.

4. Classique, hybride et post-quantique

Ecurem CLM distingue les mécanismes cryptographiques selon les preuves techniques disponibles :

  • Classique : mécanisme cryptographique traditionnel.
  • Hybride : combinaison de mécanismes classiques et post-quantiques.
  • Post-quantique : mécanisme utilisant des primitives conçues pour résister aux attaques quantiques connues.

La plateforme distingue également les actifs vulnérables au quantique et les actifs résistants au quantique lorsqu’une conclusion peut être établie à partir des données disponibles.

5. Filtres et recherche

Les cartes de synthèse peuvent être sélectionnées pour filtrer rapidement les actifs.

La recherche avancée permet également de combiner plusieurs termes :

  • les différents termes sont combinés avec une logique ET ;
  • pour un même terme, la recherche peut correspondre à plusieurs champs avec une logique OU.

Cette combinaison permet par exemple de rechercher simultanément un environnement, un algorithme ou une caractéristique observée sans perdre le contexte des autres critères.

6. Comprendre la preuve disponible

La classification dépend des informations réellement collectées. Certains actifs peuvent donc rester dans un état inconnu ou non déterminé si la plateforme ne dispose pas d’une preuve suffisante.

Important : une information manquante ne signifie ni conformité ni non-conformité. Elle signifie que les données disponibles ne permettent pas encore de conclure.

7. Relation avec Discovery

Discovery peut enrichir l’Inventaire cryptographique à partir des services, certificats et caractéristiques TLS observés dans un périmètre autorisé.

Lorsque la découverte cryptographique est disponible et activée pour la configuration concernée, les observations peuvent alimenter les informations utilisées par l’Inventaire cryptographique.

Voir la documentation Discovery.

8. Relation avec Rapports

Les données cryptographiques disponibles peuvent être exploitées par les fonctions de conformité et de reporting afin de produire des évaluations, constats et preuves.

Voir Rapports & conformité.

9. Disponibilité dans Enterprise

Dans une édition Enterprise, certaines capacités cryptographiques peuvent dépendre de l’activation réalisée par l’administrateur de plateforme pour l’organisation concernée.

Si une fonction n’est pas disponible dans votre organisation, contactez votre administrateur de plateforme.

10. Workflow recommandé

  1. Définir le périmètre d’actifs autorisé.
  2. Utiliser Discovery pour collecter les observations disponibles.
  3. Ouvrir l’Inventaire cryptographique.
  4. Examiner les cartes de synthèse et les filtres.
  5. Identifier les actifs vulnérables au quantique ou présentant un niveau de risque élevé.
  6. Vérifier les preuves techniques disponibles avant de conclure.
  7. Utiliser Rapports pour documenter l’évaluation et suivre la remédiation.
