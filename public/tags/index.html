Pourquoi utiliser les tags

Les tags organisent domaines et certificats selon votre logique : environnement, équipe, application, criticité ou groupe de renouvellement.

Ciblage opérationnel

Utilisez les tags pour limiter les opérations de masse aux objets réellement concernés et vérifiez la sélection avant lancement.

Isolation

Les tags sont interprétés dans le contexte de l’organisation. Deux organisations peuvent utiliser des noms similaires sans créer de périmètre partagé.

Convention de nommage

Adoptez une convention simple et documentée, par exemple prod, preprod, web ou renewal-auto.
