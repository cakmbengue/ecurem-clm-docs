Tags & ciblage

Séparer clairement les certificats à gérer, ceux à surveiller et ceux utilisés uniquement pour la démonstration.

Dans cette page1. Pourquoi2. Isolation3. Convention4. Renewal

1. Pourquoi utiliser les tags

Les certificats peuvent être associés à des tags d’organisation. Utilisez-les pour représenter environnement, application, responsabilité ou intention opérationnelle.

2. Isolation par organisation

Ecurem CLM bloque l’association d’un tag d’une organisation avec un certificat appartenant à une autre organisation. Un certificat doit déjà être rattaché à une organisation avant de recevoir des tags.

3. Convention recommandée

  • prod : production.
  • preprod : préproduction.
  • demo : actif visible mais non automatisé.
  • renewal-auto : actif autorisé pour un workflow automatique.
  • renewal-manual : revue humaine avant action.
  • internal / external : localisation logique.

4. Utilisation avec Renewal

Avant une opération groupée, filtrez et contrôlez les certificats sélectionnés. Le tag doit aider au ciblage, pas remplacer la validation du périmètre.

Exemple : les certificats de démonstration portent demo et ne sont jamais inclus dans le groupe renewal-auto.
