# Ecurem CLM Documentation

Public documentation repository for Ecurem CLM SaaS.

Production documentation site:

- French: https://docs.ecurem.cloud/
- English: https://docs.ecurem.cloud/en/

The legacy guide on `https://ecurem.cloud/guide` remains dedicated to
Ecurem ACM and other local products.

## Scope

This repository contains customer-facing documentation for:

- Ecurem CLM security and trust
- Discovery
- Discovery Agent
- domain validation
- Renewal
- renewal policies and targeting
- network and firewall requirements
- troubleshooting
- bilingual product guidance

Internal engineering procedures do not belong in this repository.

## Deployment

The deployable static site is under `public/`.

Production deployment is performed to the web root serving
`docs.ecurem.cloud`.
