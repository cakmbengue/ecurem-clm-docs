# Ecurem CLM Documentation

Public documentation repository for Ecurem CLM SaaS.

Production documentation site:

- French: https://docs.ecurem.cloud/
- English: https://docs.ecurem.cloud/en/

The legacy guide on `https://ecurem.cloud/guide` remains dedicated to Ecurem ACM and other local products.

## Documentation scope

- Security & trust
- Inventory
- Discovery
- Discovery Agent
- Domain validation
- Renewal
- Renewal policies
- Tags & targeting
- Network & firewall
- AI Assistant
- Reports
- Troubleshooting
- Client PKI
- FAQ

Internal engineering procedures, production paths, credentials and private operational details do not belong in this repository.

## Deployment

The deployable static site is under `public/`. Production deployment is performed to the web root serving `docs.ecurem.cloud`.

## Guidance style

Detailed operational guidance is based on the customer-facing Ecurem CLM forms, workflow states and validation rules. Internal administration routes and infrastructure procedures remain outside this public repository.

## Documentation coverage

The current public baseline covers Inventory, Discovery, Discovery Agent, domain validation, Renewal, Renewal policies, tags, network/firewall requirements, Security & trust, AI Assistant, Reports & compliance, Client PKI, troubleshooting and FAQ in French and English.
