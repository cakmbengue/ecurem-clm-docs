# Ecurem CLM Documentation

Public documentation repository for Ecurem CLM SaaS and Enterprise customer-facing capabilities.

Production documentation site:

- French: https://docs.ecurem.cloud/
- English: https://docs.ecurem.cloud/en/

The guide on `https://ecurem.cloud/guide` remains dedicated to Ecurem ACM and other local products.

## Documentation scope

- Security & trust
- Inventory
- Cryptographic Inventory, evidence & lifecycle
- Discovery
- Private Discovery / Control Plane
- Discovery Sensor / Agent
- Domain validation
- Renewal
- Renewal policies
- Tags & targeting
- Network & firewall
- AI Assistant (Aida)
- Reports & compliance
- Client PKI
- Troubleshooting
- FAQ

## October 2026 baseline

The public baseline reflects the current Ecurem CLM capabilities, including authorized public and private Discovery, reusable private scan configurations, Sensor-based work orders, verified observations, normalized cryptographic assets, observed protocol families, asset evidence/lifecycle, crypto-agility and post-quantum readiness, and read-only Aida access to authorized business data.

## Public documentation boundary

This repository intentionally excludes private credentials, enrollment/authentication tokens, passwords, private keys, customer data, production host paths, release-signing procedures, internal administration routes and implementation details that would unnecessarily expose security controls.

Internal engineering documentation belongs in the private Ecurem repositories.

## Deployment

The deployable static site is under `public/`. Production deployment is performed to the web root serving `docs.ecurem.cloud`.

## Language

Public documentation is maintained in French and English. New customer-facing capabilities must be documented in both languages before publication.
